ЗАДАЧА

Полностью заменить существующую систему идентификации логических товаров через семизначный код в описании вида #1234567 на новую систему постоянных трёхсимвольных кодов в конце названия товара.

Новая система должна использовать формат:

[AB6]
[LF9]
[MY2]

Код состоит ровно из трёх символов: латинские буквы A–Z и цифры 0–9.

Примеры:

❤️ ЗОМБИ МИШКА (43⭐) | АВТОВЫДАЧА 24/7 [AB6]

🎮 STEAM АККАУНТ | АВТОВЫДАЧА [LF9]

💝 СЕРДЕЧКО (13⭐) | АВТОВЫДАЧА [MY2]

Значения условные. Реальные коды должны генерироваться системой и закрепляться за логическими товарами.

Главное требование — полностью перейти на новую систему, а не добавить второй независимый способ привязки рядом со старым.

Нужно реализовать новую архитектуру идентификации, перенести существующие товары, изменить их названия на Playerok, удалить старые служебные #коды из описаний, сохранить все настройки и обеспечить стабильную автовыдачу после миграции.

Работа должна быть доведена до реальной, проверенной реализации.

ПРИЧИНА ПЕРЕРАБОТКИ

Сейчас Playerok при покупке иногда возвращает приватный item_id, отличающийся от ID исходного опубликованного товара.

Бот обнаруживает оплату и видит название купленного товара, но не всегда способен немедленно восстановить соответствующую LogicalProducts-привязку.

В результате возникают сообщения:

«Привязка не найдена — ожидается сверка».

Также возможен HTTP 404 при попытке вызвать get_item по приватному ID сделки.

Старая система хранит постоянный код в описании, которое может отсутствовать в первоначальном ответе Playerok по покупке.

Новая система должна использовать короткий код непосредственно из названия товара, которое уже присутствует в наблюдавшихся событиях покупки.

Однако совпадение названия или кода не является достаточным доказательством принадлежности и оплаты заказа.

Сохрани полноценную проверку серверной сделки перед любой выдачей.

# Playerok Control Center

Управление магазином Playerok из Telegram: товары, заказы, переписки, склад,
Telegram Gifts, автоматическое завершение и платное продвижение с лимитами.

## Запуск на Windows

1. Установите Python 3.12 или новее.
2. Запустите `start.bat`. Настройки храните в локальном `.env` по образцу `.env.example`.
3. Укажите токен Telegram, заголовок Playerok и ID владельца.
4. Разрешения записей, выдачи и расходов включайте явно после настройки товара.

Telegram использует системный маршрут (`TELEGRAM_TRANSPORT=direct`). На Windows
сохраняется проверка системного туннеля Happ: при его отсутствии Telegram ждёт
восстановления. Маршруты Direct для Playerok настраиваются в Happ отдельно.
Встроенного запуска VPN и подписочных прокси нет. Режим `worker` оставлен для
существующего явно настроенного адреса Bot API.

## Работа магазина

- Настройте способ выдачи товара и включите его.
- Оплаченные заказы сохраняются в SQLite и выполняются через очередь.
- Складская единица резервируется под один заказ; подтверждённая выдача не повторяется.
- Автозавершение выполняется только при подтверждённой выдаче и разрешении площадки.
- Неизвестный платёж или отправка требуют сверки; слепого повтора нет.
- STOP и финансовые лимиты сохраняются после перезапуска.

Настройка личного Telegram для подарков: [README_GIFTS.md](README_GIFTS.md).

## Данные и диагностика

`.env`, SQLite, резервные копии и Telegram-сессии не входят в Git.
Рабочие данные находятся в `data/`, технические журналы — в `logs/`.
Не публикуйте токены, cookies, секреты склада и файлы сессий.
Не запускайте несколько экземпляров на одной базе.

## Проверка разработки

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m ruff check app tests
.venv\Scripts\python.exe -m ruff format --check app tests
.venv\Scripts\python.exe -m compileall -q app tests playerokapi
.venv\Scripts\python.exe -m pip check
.venv\Scripts\python.exe -m app.selfcheck
```

Тесты используют временные базы и имитацию внешних сервисов. Успешная offline-проверка
не гарантирует доступность внешних API. Старые отчёты доступны в истории Git.

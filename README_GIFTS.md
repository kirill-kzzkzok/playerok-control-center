# Telegram Gifts

Подарки отправляются личным Telegram-аккаунтом через существующую очередь бота.

1. Заполните `TG_USER_API_ID`, `TG_USER_API_HASH` и `TG_USER_SESSION_PATH` в `.env`.
2. Выполните локальную авторизацию: `python -m app.gifts.auth`.
3. Проверьте подключение, каталог подарков и Stars в настройках бота.
4. У товара выберите Telegram Gifts, настройте состав, лимиты и включите выдачу.
5. Для платных отправок требуется отдельное `TG_GIFT_PAYMENTS_ENABLED=true`.

Сессия должна находиться в игнорируемой папке `data/`. Её нельзя передавать другим.
Telegram использует системный маршрут; на Windows защита Happ сохраняется и для
авторизации, и для отправки. При потере туннеля отправка ждёт восстановления.

Если @username отсутствует или неверен, бот запрашивает исправление у покупателя
в чате соответствующего оплаченного заказа. Получатель проверяется перед оплатой.

Начало платежа сохраняется до внешнего запроса. Результат подтверждается квитанцией
доставки каждого подарка. Таймаут и изменение Stars-баланса не доказывают доставку.
Неизвестный платёж не повторяется автоматически. STOP, бюджеты и исходные условия
заказа сохраняются при перезапуске.

Автоматическая отметка выполнения на Playerok — отдельная настройка товара.
Она возможна после подтверждённой доставки, если площадка не требует отчёта.

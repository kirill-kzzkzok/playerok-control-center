# Как заменить зомби-мишку другим Telegram-подарком в прежнем лоте

Новый лот создавать не нужно. Сохраняются item_id, LogicalProduct, [TXE], история
и старые квитанции. Сначала обновите и перезапустите бот с исправлениями.

1. **Разберите неизвестную правку, если она ещё есть.** Откройте
   «⚙️ Ещё → 🛠 Инструменты → История и результаты → Неопределённые операции».
   Выберите нужную edit-операцию, проверьте ID и товар, нажмите
   «🔍 Проверить результат на Playerok». Mutation не повторится.
   Для старой операции без сохранённой квитанции бот может подтвердить лишь
   текущее совпадение полей. Она останется неопределённой. После личной проверки
   объявления можно закрыть именно эту обычную правку кнопкой
   «⛔ Закрыть без повторной отправки»: прочитать последствия, написать причину,
   нажать «⛔ Закрыть запись без повтора». Это не подтверждение доставки подарка.
   Не используйте такое закрытие как разрешение повторить Stars-платёж.
2. **Остановите будущую выдачу старого подарка.** «📦 Товары → нужный лот →
   ⚙️ Настроить выдачу → 🎁 Состав, сообщения и лимиты». Нажмите
   «⛔ Остановить выдачу товара», если она ещё включена. Уже начатые и
   неопределённые заказы этим не отменяются и не переводятся на другой подарок.
3. **Исправьте карточку объявления.** Вернитесь в товар → «✏️ Редактировать».
   По очереди измените «Название», «Описание», «Цена и скидка»,
   «Фотографии» — только необходимые пункты. Подтвердите каждую правку и дождитесь
   результата. Сохраните [TXE]; бот защищает постоянный код. Не вписывайте
   `gift:` или старый #код. Для фото доступны добавление, замена и удаление;
   изображение можно прислать Telegram-фотографией или подходящим файлом.
   Если результат неизвестен, используйте сверку, не повторяйте сохранение вслепую.
4. **Замените пакет выдачи отдельно.** Снова откройте «⚙️ Настроить выдачу →
   🎁 Состав, сообщения и лимиты → Изменить настройки → Telegram-подарки».
   В выборе пакета нажмите **«Очистить»**, затем выберите новый подарок из
   актуального каталога. Без очистки выбор добавляет подарок в старый пакет.
   Нажмите «✅ Сохранить выбор».
5. **Проверьте условия нового подарка.** Сверьте ID, цену в Stars и количество
   в пакете. Настройте «Лимит на заказ», «Лимит в сутки», «Способ завершения»,
   «Возврат при неверном username» и «Сообщение после выдачи» по необходимости.
   Стандартное уведомление после подтверждённой доставки не является подписью
   самого Telegram-подарка. Не включайте возврат/завершение, если не хотите их.
6. **Подтвердите новую привязку.** Нажмите «🔎 Проверить и посмотреть превью»,
   проверьте состав и стоимость → «✅ Подтвердить привязку».
   Затем «🔄 Проверить результат». Запись в очереди ещё не означает успех.
   Должна появиться подтверждённая привязка нового состава с прежним [TXE].
   На этом этапе автовыдача ещё выключена.
7. **Явно включите будущие заказы.** Нажмите «▶️ Включить выдачу» и выберите
   «Включить только это объявление» либо «Включить и наследовать перевыставления».
   Второй вариант сохраняет разрешение для проверенных перевыставлений с тем же
   кодом; не даёт права сопоставлять товары только по названию.
8. **Проверьте готовность.** В карточке нажмите «🔍 Проверить готовность».
   Бот проверяет актуальный лот, привязку, Telegram-сессию, каталог, баланс и
   лимиты без покупки подарка. Устраните конкретные причины блокировки.
   Глобальный STOP/выключенные разрешения локальной кнопкой не обходятся.

Обычный `bear` и `zombie_bear` — разные gift_id. Наличие обычного мишки нельзя
предполагать: выбирайте только реально доступный сейчас подарок. Изменение
цены в Stars требует нового согласования. Редактирование объявления само по
себе не заменяет пакет и не разрешает покупку.

Если есть старый оплаченный заказ, частичная выдача или неизвестный Stars-платёж,
разбирайте его отдельно через историю/сверку. Новый пакет применяется к новым
разрешённым заказам; ручную уже выполненную отправку нельзя повторять.
